# 🐍 スネークゲーム

ブラウザで動く、依存ライブラリなしのシンプルなスネークゲームです。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。

## 操作方法

| 操作 | キー |
|------|------|
| 移動 | 矢印キー または `W` `A` `S` `D` |
| 一時停止 / 再開 | スペースキー |
| スマホ | 画面をスワイプ、または画面下のボタン |

## ルール

- エサ（赤い丸）を食べるとスコアが 10 点増え、ヘビが 1 マス伸びます。
- 食べるたびに少しずつスピードが上がります。
- 壁または自分の体にぶつかるとゲームオーバーです。
- ハイスコアはブラウザに自動保存されます。

## 技術

- HTML / CSS / Canvas + 素の JavaScript（フレームワーク・外部依存なし）
- 単一ファイル完結
